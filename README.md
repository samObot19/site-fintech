# Samuel F. Legesse — Fintech Portfolio

Backend-engineer portfolio positioned for **financial infrastructure** roles.

Reframes the résumé through a fintech lens — USSD banking backends, transaction paths, KYC, multi-tenant SaaS patterns — and presents it in a trading-terminal + private-banking-dossier design language.

Built with **Next.js 14 · React 18 · TypeScript · Tailwind CSS · Framer Motion**, set in **Manrope** and **JetBrains Mono**. Deep navy carbon on a burnished-amber accent, single dark theme.

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:5000

## Build

```bash
npm run build
npm start
```

## Deploy

Stock Next.js project. Deploy on [Vercel](https://vercel.com/new) by importing the repo.

## Structure

```
app/            Route + layout (App Router)
components/     Dossier / terminal-styled section components
lib/            Portfolio content (fintech-framed) and utilities
```

Content lives in [`lib/data.ts`](./lib/data.ts) — reframed for fintech relevance.
